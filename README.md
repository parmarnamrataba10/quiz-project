# 💜 Quiz App

A simple and interactive **Quiz App** built using HTML, CSS, JavaScript, and Bootstrap. This project allows users to answer multiple-choice questions, track their progress, and complete the quiz within a time limit.

## ✨ Features

- 🎯 Multiple-choice quiz questions
- 💜 Four options for each question
- ⏱️ Countdown timer for each question
- 📊 Question number and progress display
- 🎨 Attractive purple-themed UI
- 🖱️ Interactive option buttons with hover effects
- ➡️ Next Question button
- 📱 Clean and user-friendly design

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, background image, and button effects
- **JavaScript** – Quiz logic, answer selection, and timer functionality
- **Bootstrap 5** – Layout and styling components

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all the project files are in the correct location.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.
5. Start answering the quiz questions!

## 🎮 How to Use

1. Open the Quiz App.
2. Read the displayed question.
3. Select one of the four options.
4. Click **Next Question** to continue.
5. Complete the quiz and view the result, if result functionality is implemented.

## 🎨 Design

The application uses a soft purple background, a centered white quiz card, purple option buttons, and a countdown timer to create a clean and attractive user experience.
